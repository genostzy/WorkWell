Design system

The pieces every screen is assembled from.

Plane accents

Two accents distinguish plane context. Both meet WCAG AA as text on their own plane's background, in both light and dark. Critically, they are never the only signal — an icon and a written label always accompany them.

Drag scale — the check-in inputs

One component, two drawings. Drag the mouth corners or the battery fill line up and down. Each is an ARIA slider first: arrow keys, Home/End and the word chips set the same value, and the drawing is always rendered from the value that will be recorded — never from the raw pointer position. Both use a single accent colour at every level; colouring "empty" red would be a verdict on the person.

Pressure drags horizontally and maps from distance to centre, so either plate works. Workload is a centred scale — the beam levels at "About right", which a fill level cannot express.

Charts

Every chart is single-series or a single-hue sequential ramp — the data's job here is magnitude and change over time, never identity, so the categorical palette is deliberately never used. 2px lines, 8px markers, 4px rounded bar ends, a 2px gap between adjacent bars, recessive grid. All ship a hover layer and a table view.

Screen states

Five states, each visually distinct. "Empty" and "not enough data yet" are deliberately different components: empty means nothing exists, thin means data exists but is too sparse to describe honestly.

Locked group

The org plane's most important component. A suppressed cohort is replaced entirely by its explanation — never a blurred chart, never a partial figure, never an estimate. Named rather than silently dropped, so the gap can't be read as a signal.

Research

Not shown — fewer than 8 people in this group, to protect anonymity.

Why? This group has 4 people contributing data in the selected window. Below 8, a group average can be worked backwards toward an individual, so the metric is withheld entirely rather than estimated or blurred.
The rule in code

Suppression is enforced once, where cohorts are selected — orgCohorts() recomputes contributing headcount for the active filter and sets locked. Every renderer downstream receives the same list and must not read metric fields from a locked cohort. This is why narrowing the date range re-locks groups: the threshold is applied to the filtered result, not to the original group size.

Icons

24px grid, 1.8 stroke, rounded joins to match the typeface. Decorative by default; pass a label to expose one to assistive technology.

Typography

Nunito, with a rounded system fallback. Headings are heavy and slightly tightened; body copy runs at 1.6 line-height and is capped near 68 characters.
